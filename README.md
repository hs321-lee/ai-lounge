# AI 라운지 · AI Lounge

**AI 소식부터, 나는 이렇게 쓴다까지.** 매일 모으고, 매달 고르고, 직접 써본 경험을 나누는 공간입니다.

## 첫 버전

- **대시보드:** 발행 현황과 최근 기록, 공유 방법
- **월간 공유:** 추려서 소개할 AI 동향, 실제 사용 사례, 소소한 팁
- **데일리 리포트:** 출처와 날짜를 갖춘 시스템 보고 기록
- 제목·본문·태그 검색과 주제 필터, 개별 기록 주소, 모바일 화면

현재 발행된 월간·데일리 기록은 **0건**이며, 시작 가이드만 들어 있습니다. 자동 수집·요약·일일 실행은 아직 연결하지 않았습니다. 화면의 수치는 실제 콘텐츠에서 계산합니다.

## 실행

빌드나 패키지 설치 없이 실행합니다. JSON을 읽으므로 HTML 파일을 직접 열지 말고 로컬 서버를 사용합니다.

```sh
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

```sh
npm run check
```

Node.js 20 이상에서 JavaScript 문법과 콘텐츠 형식·중복 ID·날짜·출처를 검사합니다.

## 콘텐츠 추가

1. `templates/monthly.json` 또는 `templates/daily.json`의 항목을 복사합니다.
2. `data/posts.json`의 `posts` 배열에 넣고 실제 내용으로 채웁니다. 템플릿 파일은 직접 표시되지 않습니다.
3. 날짜는 `YYYY-MM-DD`, `id`는 영문 소문자·숫자·하이픈으로 고유하게 정합니다.
4. 최신 기록부터 날짜 내림차순으로 표시됩니다. 주소는 `#post/고유-id`입니다.
5. `npm run check`를 실행하고 브라우저에서 확인합니다.

### 공통 데이터 계약

| 필드 | 내용 |
| --- | --- |
| `id` | 고유한 영문 ID |
| `type` | `guide`, `monthly`, `daily` |
| `date` | 발행일 `YYYY-MM-DD` |
| `title`, `summary`, `author` | 제목, 짧은 요약, 작성자·시스템명 |
| `tags` | 주제 문자열 배열 |
| `sections` | `{ "heading": "소제목", "body": "본문" }` 배열. 본문은 일반 텍스트이며 줄바꿈 지원 |
| `sources` | `{ "title": "원문 이름", "url": "https://…" }` 배열 |

데일리 리포트에는 최소 하나의 HTTPS 원문 출처가 필요합니다. 월간 공유도 외부 소식을 인용할 때 원문을 붙입니다. 사용하지 않은 도구를 사용 사례로 쓰거나 측정하지 않은 효과를 수치로 제시하지 않습니다. 공개 저장소이므로 회사 내부 코드, 고객 정보, 사내 링크, 비밀키를 올리지 않습니다.
