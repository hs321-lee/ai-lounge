# 명세 6칸으로 요청 정리하기

김덕진 『AI 2027』 강연 자료 29쪽의 '명세 6칸'을 AI 라운지가 스킬 형태로 옮긴 것입니다.
요청을 바로 실행하지 않고, 먼저 여섯 칸이 채워졌는지 확인합니다.

## 여섯 칸

| 칸 | 확인할 질문 |
|---|---|
| 1. 목표 | 무엇을, 왜 하려는가? 결과물은 어디에 쓰는가? |
| 2. 맥락 | 누가 읽는가? 어떤 상황인가? 요청하는 사람은 누구인가? |
| 3. 자료 | AI가 참고할 원문·데이터·숫자는 무엇인가? 구분자로 감쌌는가? |
| 4. 조건 | 지킬 것과 하지 말 것은? 범위·분량·금지어는? |
| 5. 형식 | 표·목록·문단·파일 중 무엇으로 받는가? 길이와 순서는? |
| 6. 기준 | 무엇이면 잘된 답인가? 모르는 것은 어떻게 처리하는가? |

## 진행 순서

1. 사용자의 요청을 읽고 여섯 칸에 나눠 적습니다.
2. 비어 있거나 애매한 칸을 표시합니다. 추측해서 채우지 않습니다.
3. 빈 칸은 한 번에 모아서 짧게 질문합니다. 기본값을 제안할 수는 있지만, 기본값이라고 밝힙니다.
4. 여섯 칸이 채워진 명세를 보여 주고 확인을 받습니다.
5. 확인받은 명세대로 작업합니다.
6. 결과를 낸 뒤, '기준' 칸에 비추어 스스로 점검한 내용을 한두 줄로 덧붙입니다.

## 지킬 것

- 자료에 없는 숫자나 사실은 만들지 않습니다. 없으면 "확인 필요"로 표시합니다.
- 사용자가 급하다고 하면 3~4단계를 줄이되, 비어 있는 칸은 결과물 끝에 알려 줍니다.
- 결과가 기대와 다르다는 말을 들으면, 모델이나 표현을 바꾸기 전에 빠진 칸부터 다시 확인합니다.

## 명세 틀

```
[목표] 
[맥락] 
[자료] """ 여기에 원문·데이터 """
[조건] 
[형식] 
[기준] 
```
